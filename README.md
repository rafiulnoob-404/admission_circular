# admission_circular

Admission Circular for 2026-27

## ফাইল

| ফাইল | কী |
|---|---|
| `index.html` | ১৬টি বিশ্ববিদ্যালয়/মেডিকেলের ভর্তি ফ্ল্যাশ কার্ড |
| `eligibility.html` | Elig//যোগ্যতা যাচাই (SSC+HSC GPA → কোন ইউনিটে আবেদন করা যাবে) |
| `calendar.html` | ভর্তি পরীক্ষার ক্যালেন্ডার (সার্চ + ইউনিভার্সিটি ফিল্টার) |
| `du-science.html` | ঢাবি বিজ্ঞান ইউনিটের নির্দেশিকা ও বিভাগভিত্তিক ন্যূনতম শর্ত |
| `STYLE_GUIDE.md` | স্টাইল-নিয়ম (প্যালেট, টাইপ, অংশ, রেফ-কার্ড, অ্যানিমেশন) |
| `CARD_MAP.md` | কার্ডের ভেতরের অর্ডার, ডেটা → জায়গা ম্যাপিং, Elig ফ্লো |

> এই রিপোতে বিল্ড-স্ক্রিপ্ট নেই — `index.html` (মার্কআপ + `card-data` JSON মিরর),
> `eligibility.html` (`UNIS`) আর `calendar.html` (`EV`) সরাসরি এডিট করা হয়।

## আপডেট লগ

- **১১ নভেম্বর ২০২৬** — দেওয়া বিজ্ঞান ইউনিট নির্দেশিকার পৃষ্ঠা ৪–৯ এবং অনলাইন অনুলিপি অনুযায়ী ঢাবি কার্ডে পরীক্ষার নিয়ম ও বিষয়ভিত্তিক শর্তের বিস্তারিত যোগ; মানবিক/ব্যবসায় শাখার আবেদনযোগ্যতা যোগ এবং যাচাইয়ের সীমাবদ্ধতা জানানো।

- **১১ নভেম্বর ২০২৬** — সংবাদ অনুযায়ী রাবি, খুবি ও এমআইএসটির পুনর্নির্ধারিত পরীক্ষার তারিখ; চবি, জবি ও কুবির আবেদন সূচি; যবিপ্রবির গুচ্ছে থাকার তথ্য কার্ড ও ক্যালেন্ডারে আপডেট। রাবির যোগ্যতার সংবাদে মতভেদ ও এমআইএসটির নতুন যোগ্যতা বিজ্ঞপ্তি না পাওয়ায় স্বয়ংক্রিয় হিসাব বন্ধ।

- **৭ নভেম্বর ২০২৬** — BUET কার্ড (p-steel) + সোর্স বক্স স্টাইল
- **৭ নভেম্বর ২০২৬** — সব কার্ডে টাইপোগ্রাফি স্কেল বড় (মোবাইলে পড়ার সুবিধা)
- **৭ নভেম্বর ২০২৬** — `calendar.html` পেজ + ইনডেক্সের হেডার/টুলবার/মোবাইল বারে ক্যালেন্ডার বাটন
- **৭ নভেম্বর ২০২৬** — `eligibility.html`-এর `.headlink` ডাবল-ব্রেস CSS বাগ ফিক্স
- **৭ নভেম্বর ২০২৬** — তিন পেজে এক শেয়ার্ড হেডার (সব কার্ড / Elig // ক্যালেন্ডার + active পেজ), সাথে `index.html` ও `calendar.html`-এর unclosed `@media` ফিক্স
- **৮ নভেম্বর ২০২৬** — রাবি (রাজশাহী বিশ্ববিদ্যালয়) ২০২৬-২৭ আপডেট: আবেদন ১২–২৭ নভেম্বর (আগে ভুল ছিল), ৭ বিভাগীয় শহরের কেন্দ্র, যোগ্যতা শিথিলের নোট (মানবিক ৩.০০/৬.৫০ · বিজ্ঞান ৩.৫০/৭.০০), পোর্টাল `admission.ru.ac.bd`, সোর্স বক্স
- **৮ নভেম্বর ২০২৬** — রাবি কার্ড **রেফ-কার্ড** হলো (`.ref` + `.refpill` + `.hero-date` বাদ), §৫ অনুযায়ী ব্যাজ "সংবাদ সূত্র"; `card-data`-এ `centers` গ্রিডে সরানো (কার্ড ম্যাপ §২)
- **৮ নভেম্বর ২০২৬** — `STYLE_GUIDE.md` + `CARD_MAP.md` রিপোতে যোগ, README লগ চালু
- **৮ নভেম্বর ২০২৬** — রাবির "যোগ্যতা শিথিল (আগে …)" বুলেট বাদ (শুধু ২০২৬-২৭ তথ্য); টুলবার ও মোবাইল বারে ডুপ্লিকেট Elig // ক্যালেন্ডার বাটন বাদ — হেডারেই একবার; হেডারের টাইপরাইটার অ্যানিমেশন এখন তিন পেজেই একই
- **৯ নভেম্বর ২০২৬** — ইউজিসির ৯ নভেম্বরের সিদ্ধান্ত (আবেদন জানুয়ারি ২০২৭ · পরীক্ষা ফেব্রুয়ারি ২০২৭ · রমজানে পরীক্ষা নয়) তিন পেজেই নতুন `.notice` স্ট্রিপে; ঢাবি ও বুয়েট আগের সূচিতেই থাকছে। মেডিকেল-ডেন্টাল: ৪ ডিসেম্বরের পরীক্ষা পিছিয়ে **১৮ ডিসেম্বর ২০২৬** (কার্ড এখন রেফ-কার্ড, সোর্স প্রথম আলো)। ঢাবি কার্ডের তথ্য যাচাই ৯ নভেম্বর, `calendar.html`-এ নতুন তারিখ + ইউজিসি নির্দেশনার এন্ট্রি, `eligibility.html`-এ "হালনাগাদ সূচি" প্যানেল
